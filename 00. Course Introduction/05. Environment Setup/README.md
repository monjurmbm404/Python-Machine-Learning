# 📖 Overview

Before building Machine Learning models, you need a well-configured development environment.

A proper environment helps you:

- Write clean Python code
- Manage project dependencies
- Run Jupyter notebooks
- Build reproducible Machine Learning projects
- Avoid version conflicts between libraries

In this lesson, you'll install all the tools required for the rest of the course.

# 📌 Best Practices

- Install the latest stable version of Python.
- Use a separate virtual environment for each project.
- Keep your `requirements.txt` file updated.
- Store notebooks, datasets, and source code in organized folders.
- Use Git to track your project changes.
- Push your work to GitHub regularly.
