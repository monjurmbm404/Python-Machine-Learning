# 1. What is Machine Learning?

## Definition

Machine Learning (ML) is a branch of **Artificial Intelligence (AI)** that allows computers to learn from data, identify patterns, and make decisions or predictions without being explicitly programmed for every task.

### Simple Definition:

> Machine Learning is teaching computers to learn from experience (data).

---

## Traditional Programming vs Machine Learning

### Traditional Programming

In traditional programming, humans create rules and provide data to get output.

```
Rules + Data
      ↓
  Computer Program
      ↓
     Output
```

Example:

Calculating tax:

```
Income + Tax Rules
        ↓
    Tax Calculator
        ↓
     Tax Amount
```

---

### Machine Learning Approach

In Machine Learning, computers learn the rules from examples.

```
Data + Expected Output
          ↓
    ML Algorithm
          ↓
      Model
          ↓
  New Predictions
```

Example:

Email Spam Detection:

```
Thousands of Emails
          ↓
 ML Algorithm learns patterns
          ↓
 Spam Detection Model
          ↓
 New Email Classification
```

# 3. Why Do We Need Machine Learning?

Traditional programming works well when rules are clear.

But many modern problems are too complex for humans to manually create rules.

---

## Problem 1: Huge Amount of Data

Modern systems generate massive amounts of data.

Examples:

* Social media posts
* Images
* Videos
* Sensor data

Humans cannot analyze all this data manually.

ML helps discover hidden patterns.

---

## Problem 2: Complex Problems

Some problems are difficult to solve with fixed rules.

Examples:

### Face Recognition

A face changes because of:

* Lighting
* Angle
* Expression
* Age

Writing thousands of rules is impossible.

ML learns these patterns automatically.

---

## Problem 3: Automation

Machine Learning can automate decision-making tasks.

Examples:

* Spam filtering
* Product recommendation
* Fraud detection

---

# 8. Common Machine Learning Terms

## Dataset

A collection of data used for training and testing ML models.

Example:

House price dataset.

---

## Feature

Input information used by a model.

Example:

House prediction:

Features:

* Size
* Location
* Number of rooms

---

## Label / Target

The output we want to predict.

Example:

House price.

---

## Model

A mathematical system that learns patterns from data.

Example:

Linear Regression model.

---

## Training

The process of teaching a model using data.

---

## Prediction

Using a trained model to make decisions on new data.
